# Digit All or Nothing — Digital Accessibility Guide

A responsive, static educational website using HTML, CSS and JavaScript.

## Preview locally

Open `index.html` in Safari or Chrome. No build tools are required. Google Fonts loads when connected to the internet; system font fallbacks work offline.

## Publish on GitHub Pages

1. Create a public GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder at the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. After the site is published, copy its final HTTPS URL and use that URL to generate the bookmark QR code.

## Before publication

- The device illustration is a concept, **not** a genuine settings screenshot. Replace it with verified, appropriately described screenshots of actual devices, ideally labeled by OS version.
- Verify instructions for the actual versions of Android, iOS, macOS and Windows the audience uses.
- Test keyboard navigation, screen reader labels, mobile layout, and colour contrast (especially illustrative poor-design examples).
- Replace illustrative graphics if original separate artwork is preferred; the supplied illustration assets were cropped from the approved storyboard.
- No quiz or separate resource section was included, per the six-section locked scope.
